# 神州侵防戰：霹靂天罪自走棋（v11）

以霹靂神州三部曲為主題的 TFT 式自走棋網頁遊戲。
副標：**魔界進攻 · 中原防守**

> 本作為非官方免費同人遊戲，角色出處與羈絆設定為遊戲化改編，非嚴謹劇集考據；霹靂相關名稱版權歸原權利方所有。

## 零、v11 更新重點（降低難度＋勝負規則）

1. **勝負規則改為「血量制」**
   - **中原正道（守方）**：戰鬥失敗扣「神州血量」，歸零落敗；撐過 16 波血量未歸零＝守住神州。
   - **異度魔界（攻方）**：戰鬥獲勝會削減「神州神柱」（100，每勝 6＋2×存活人數，上限 18）；16 波內推倒神柱＝入侵成功；16 波未攻下或「魔軍血量」歸零＝退兵回魔界。
2. **修正敵方陣營**：敵人只會從「對立陣營＋中立」抽取（選中原→敵方為魔界／東瀛／獨立梟雄；選魔界→敵方為苦境正道／玄宗道門），且不再出現 6 費終極角色。
3. **難度下調**：敵方數量、血量倍率、攻擊倍率全面調降（無 3★ 敵人、最高 5 費）；我方血量 ×1.25；失敗扣血改為 1＋敵方存活數（上限 8）；前 2 回合失敗不扣血。
4. **經濟寬鬆**：起始金 15、每回合基礎收入 6、自然經驗 +5、選完陣營直接 3 級。
5. **最終防線更快降臨**：戰場神柱削減速度提高（約 17 秒降到 30 以下）。
6. 修正頂部「等級 (2/4)」被畫成獨立膠囊的樣式問題。

> 數值集中在 `data.js` 底部（`ROUNDS`、`PLAYER_HP_MUL`、`LOSE_DMG_MAX`、`SIEGE_*`、`PILLAR_DRAIN` 等），想再調難度只要改這裡。

## 一、v10 更新重點

1. **陣營分組採「方案 B」完全平均**：中原方 21 名（苦境正道 15 ＋ 玄宗道門 6）、魔界方 21 名（異度魔界 12 ＋ 東瀛 6 ＋ 獨立梟雄 3）、中立 9 名（紅樓劍閣 4 ＋ 識界靈體 5）。兩大陣營商店可招募池各為 **30 名**（各含中立 9）。
2. **經驗值調高**：自然經驗由每回合 +2 提高為 **+4**；升級所需 XP 調平；**等級上限提高至 12 級**，可上場人數上限提高至 **12 人**（後期不再因位置不足被壓制）。

   - 選擇「異度魔界」→ **棄天帝** 作為最終王牌降臨
   - 三位終極角色皆為 **6 費**，並新增專屬羈絆「最終防線」（1／2 人）與「最終王牌」（1 人）。
4. **修正三星 Bug**：角色升至 **3★** 後，商店**不再出現該角色**（自可抽取池移除），不再佔用卡片格。
5. **遊戲更名為《神州侵防戰》**（副標：魔界進攻 · 中原防守）。

## 五、部署到 GitHub Pages（步驟）

1. 登入 GitHub，點右上角 **＋ → New repository**。
2. Repository name 填例如 `pili-shenzhou-auto-chess`，設為 **Public**，按 **Create repository**。
3. 進入新 repo，點 **Add file → Upload files**。
4. 將本 ZIP 解壓後的 **5 個檔案**（`index.html`、`data.js`、`main.js`、`style.css`、`README.md`）一起拖入，按 **Commit changes**。
5. 進入 repo 的 **Settings → Pages**。
6. **Source** 選 `Deploy from a branch`；**Branch** 選 `main`，資料夾選 `/ (root)`，按 **Save**。
7. 等待約 1～2 分鐘，重新整理 Pages 頁面，會顯示網址：
   `https://<你的帳號>.github.io/<repo 名稱>/`
8. 點擊該網址即可遊玩。日後更新只需重新上傳覆蓋檔案即可。

### 常見問題

| 問題 | 原因 | 解決方式 |
|---|---|---|
| 開啟後畫面空白 | 只上傳了 index.html，缺少 js/css | 確認 5 個檔案都在 repo 根目錄 |
| 404 找不到頁面 | Pages 尚未建置完成 | 等待 1～2 分鐘後重新整理 |
| 樣式跑掉、像純文字 | 檔名大小寫不符 | 確認檔名為 `style.css`、`main.js`（全小寫）|
| 改了檔案但畫面沒變 | 瀏覽器快取 | 按 Ctrl+F5（Mac：Cmd+Shift+R）強制重新整理 |
| 商店出現敵對陣營角色 | 使用了舊版 data.js | 確認 data.js 為 v10 版本 |
| 遊戲顯示「載入失敗」 | 檔案未完整上傳 | 重新上傳全部 5 個檔案 |

## 六、玩法簡介

- **開局**：先選「中原正道」或「異度魔界」陣營。
- **準備階段**：用金幣在商店購買俠客（拖放到棋盤或備戰區），可花 2 金刷新商店、4 金買經驗；集滿 3 張同名同星角色自動升星（1★→2★→3★）。
- **羈絆**：棋盤上同陣營／同職業角色達門檻即觸發效果（左側面板即時顯示）。
- **戰鬥**：雙方自動尋敵、普攻、集氣施放技能；一方全滅即分勝負。
- **神柱**：戰鬥中神柱耐久會被削減，降至 30 以下時最終防線降臨。
- **勝負**：戰鬥失敗會扣生命值，生命歸零落敗；撐過 16 波即勝利。
