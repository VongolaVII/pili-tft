# 霹靂神州：天罪自走棋（v7）

非官方免費同人自走棋遊戲。以霹靂布袋戲「霹靂神州」時期角色為題材。

## 檔案說明
- `index.html` — 遊戲主頁（入口）
- `data.js` — 角色／羈絆／技能資料
- `main.js` — 遊戲主邏輯
- `style.css` — 樣式表

## 部署到 GitHub Pages（三步驟）
1. **建立倉庫**：登入 GitHub → 右上 `+` → `New repository` → 命名（例如 `pili-auto-chess`）→ 選 **Public** → `Create repository`。
2. **上傳檔案**：進入倉庫 → `Add file` → `Upload files` → 將本資料夾的 4 個檔案（index.html、data.js、main.js、style.css）拖入 → `Commit changes`。
3. **開啟 Pages**：`Settings` → 左側 `Pages` → Source 選 **Deploy from a branch** → Branch 選 **main**、資料夾選 **/ (root)** → `Save`。

約 1～2 分鐘後，即可用 `https://你的帳號.github.io/pili-auto-chess/` 遊玩。

## 常見問題
- **畫面空白**：確認 4 個檔案都在倉庫根目錄（不是放在子資料夾）。
- **樣式跑掉**：確認 `style.css` 已上傳且檔名大小寫一致。
- **更新後沒變化**：GitHub Pages 有快取，稍等 1～2 分鐘或強制重新整理（Ctrl+F5）。
